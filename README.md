## The slogan

> One wallet, one agent, zero waiting: Solana at the speed of a sentence.

13 words, 71 characters, one line. A triplet rhythm (one / one / zero) that is easy to repeat, and a fresh image — "the speed of a sentence" — that ties the wallet agent's plain-language trick to Solana's speed in a single phrase. It names the wallet, the agent, and Solana outright, stays in plain words a newcomer grasps on one read, and promises only speed, never an outcome it cannot deliver.

## How it runs

`main.ts` writes the slogan to `/output/entry.txt`, then re-reads the bytes and re-checks the gate: one line, at most 20 words, 1–140 characters, no trailing newline, and nothing else left in the output directory.

```sh
node main.ts
```

## Design

See the prose design spec (candidate slogans weighed against the judge's published criteria) in the build notes. The slogan was written fresh for this entry — no entrant line was read, copied, or paraphrased.
